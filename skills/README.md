# Holistic Edge Workspace Skills

This directory contains all 15 custom workspace skills for the Holistic Edge workspace.
Import any skill into Lovable via: Settings → Skills → Add → Write manually.

| # | Skill Name | When to Use |

| 01 | `sequential-build-protocol` | Any multi-phase or multi-step build |
| 02 | `holistic-edge-design` | Any UI work across any project |
| 03 | `edge-function-scaffold` | Adding any edge function or API endpoint |
| 04 | `agentic-feature-scaffold` | Adding any AI agent or autonomous workflow |
| 05 | `deep-debug` | Diagnosing any bug or unexpected behavior |
| 06 | `pre-launch-checklist` | Before publishing or going live |
| 07 | `security-audit` | Full security review, compliance prep |

| 11 | `production-feature-validator` | After shipping any feature |
| 12 | `generate-knowledge-base` | Onboarding, before refactor, complex codebase |
| 13 | `clean-spaghetti-code` | Refactoring large or messy files |
| 14 | `ai-discoverability` | Making any project findable by AI search |
| 15 | `post-generation-security-audit` | After any new feature or table is generated |

## How to Import
1. Go to lovable.dev → Settings → Skills → Add → Write manually
2. Copy the Name, Description, and Content from each SKILL.md
3. Click "Add skill"
4. Enable "Automatic use" for skills you want Lovable to apply without prompting

## Recommended Auto-Enable
- `sequential-build-protocol` ← most important
- `holistic-edge-design`
